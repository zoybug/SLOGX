4th Task: let's focus on user interface a bit:

### Source line (footer)

**Current behaviour:** The footer under the chart reads something like: *Source: UNCTADstat US.PLSCI, downloaded 3 Jun 2026. Index base: …* (the download date is shown).

**Required change:** Remove the download date entirely. Replace it with:

> as per the data of 25 Mar. 2026

The rest of the source line should stay as-is (UNCTADstat link/series, index base, rescaling note, country/port counts). Example target wording:

> Source: UNCTADstat US.PLSCI, as per the data of 25 Mar. 2026. Index base: average global port connectivity Q1 2023 = 100. Levels from 2024 onward follow UNCTAD rescaling — compare within-era. 186 countries, 1349 ports.

### Chart zoom (in / out)

**Current behaviour:** The main line chart (Plotly) allows scroll-wheel zoom and axis zoom with no hard limits on the Y-axis. Users can zoom in so far that the graph looks stretched or distorted, or zoom out to an empty margin with little useful detail.

**Required change:** Keep zoom and pan useful, but **clamp** both axes to sensible bounds so the chart cannot be distorted beyond the data’s meaningful range.

- **X-axis (Year):** Already tied to the selected year range (e.g. 2006–2023). Zoom/pan should not go outside that range (or only a very small padding, e.g. ±0.4 years).
- **Y-axis (PLSCI):** Limit zoom so the visible range stays between **0** and a **maximum** derived from the data shown (e.g. top port value for the selected year/countries, plus a modest headroom margin — not unbounded zoom into infinity or zoom-out to huge empty space).
- **Goal:** A visitor can still inspect detail near interesting ports, but cannot break the scale so lines look wrong or the plot area is mostly blank margin.

**Acceptance:** After zooming in/out repeatedly (scroll, toolbar +/-, box zoom, reset), the chart always returns to a readable scale within these limits; reset returns to the default full view for the current country selection and year range.

### Visual & aesthetic improvements

- **Tighter colour discipline in compare mode** — Many similar hues make 20 lines hard to read; cap palette size, soften non-focused lines, and lean on solid vs dashed + country tint instead of 10 distinct colours per side.
- **Stronger hierarchy** — Larger chart title and country names; lighter axis/grid labels so data lines are the focal point.
- **Refined control bar** — Group filters (country / year / display) into labelled sections; align heights; use a single dual-handle year slider instead of two stacked sliders.
- **Country codes in UI** — Show ISO abbreviations (CHN, ARE) beside full names in dropdowns, legend, and chart labels once the abbreviation map is wired in.
- **Ranking panel polish** — Top 3 with subtle medal tint or weight; larger PLSCI values; optional mini sparkline per port; sync highlight state more visibly with the chart.
- **Header treatment** — Short tagline under the title, optional subtle maritime gradient or map watermark, and a compact “About / PLSCI” link.
- **Chart chrome** — Custom Plotly theme (font, grid, margins) to match site colours; hide or slim the default Plotly toolbar; rounded plot area padding.
- **Motion** — Smooth year transitions during Play; gentle fade when switching country or compare mode.
- **Dark mode** — Optional theme toggle (CSS variables already make this feasible).
- **Mobile layout** — Stack chart above rankings earlier; sticky controls; touch-friendly sliders and rank rows.
- **Footer** — Clickable UNCTAD link, slightly smaller muted text, clear rescaling disclaimer as a discrete badge or tooltip.

### Cool features (plausible)

- **Searchable country picker** — Type-to-filter on long country lists (186 entries).
- **Shareable view URL** — Encode country A/B, year range, top N, compare mode in query params so a link restores the exact view.
- **Export** — Download chart as PNG; export visible table as CSV (country, port, year, PLSCI).
- **Year scrubber on chart** — Draggable playhead under the x-axis, synced with Play/Pause and ranking year badge.
- **YoY delta in rankings** — Show ▲/▼ vs prior year next to each port’s PLSCI.
- **Gap summary in compare mode** — One-line stat: leading country, largest port gap, and change since start of range.
- **Presets** — Quick picks: “China vs India”, “Top hub ports”, “My last view”.
- **Rescale-era guardrail** — Toggle or banner when range crosses 2024 so users don’t mix pre/post-rescale years without noticing.
- **Port search / isolate** — Filter to one port or “show only highlighted” to declutter busy charts.
- **Keyboard shortcuts** — Space = play/pause, Esc = clear highlight, arrows = step year.
- **Definitions drawer** — Slide-over with short PLSCI definition + link to UNCTAD (from `definitions.md`).
- **Copy citation** — One click to copy source line for reports.
