# 2025 lecture illustrations

Conceptual, text-free illustrations created with the built-in image generation tool for Lectures 01–07 and the industry visit. Each WebP is 1536 × 1024 pixels. The source concepts follow the lecture titles and briefs; they do not depict real speakers, facilities or exact case studies. The previous SVG hero assets remain in 2025-theme/. The guest lecture and industry visit illustrations use generic people and unbranded settings.

The active illustrations use the `-transparent.webp` versions, which preserve genuine alpha transparency after background extraction with the built-in image generation tool. Earlier assets remain available as originals.
