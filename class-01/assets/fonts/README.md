Source Sans 3 and Source Serif 4 variable WOFF2 files are the active course fonts.

They are unmodified Google Fonts subsets of Adobe's Source families, downloaded 10 October 2026. `source-fonts.css` defines normal/italic faces for weights 400–600, with Unicode ranges so only needed subsets load. The two normal Latin subsets total about 148 KiB and are preloaded. Source Serif 4 includes optical sizing. The included Source-Sans-3-OFL.txt and Source-Serif-4-OFL.txt contain their SIL Open Font Licenses.

Sources: https://github.com/google/fonts/tree/main/ofl/sourcesans3 and https://github.com/google/fonts/tree/main/ofl/sourceserif4

Noto CJK and local system fallbacks handle unsupported scripts. No external font requests are made by the course site.

The earlier IBM Plex Sans (Regular, Medium, SemiBold, Bold) and IBM Plex Mono (Medium) files remain available for existing assets and documents.

Unmodified WOFF2 files from the official IBM Plex repository: https://github.com/IBM/plex
Downloaded 4 October 2026. The included IBM-Plex-LICENSE.txt contains the SIL Open Font License.
