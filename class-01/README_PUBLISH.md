# Introduction to Smart Logistics / Class Atlas

This folder is a self-contained course site. `index.html` opens the eight-lecture register. Lecture 01 has four vertical sections: lecture intro, a full-height horizontally scrollable five-part student slideshow that begins with its table of contents, references, and a 20-question decision lab. The slideshow keeps its scroll and progress controls at the bottom while slide content scrolls within the frame. The unified top navigation links the four sections and lists the eight lectures. The `interactive/` address redirects to Lecture 01 so existing links still work. PDFs, a high-resolution PNG, an editable SVG poster, and an editable HTML brief are included. No build step is required.

## GitHub Pages

Copy the **contents** of this folder into the directory that GitHub Pages publishes. Keep the `assets`, `lecture-01`, and `interactive` folders beside the PDFs so their relative links work. The public version lives at `/SLOGX/class-01/`.
